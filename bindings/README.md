# bindings

Go bindings for the contracts supersim interacts with.

These started out generated by `abigen` but are now maintained by hand. The
generator recipe was removed because the artifact bucket it downloaded from
stopped being published, and because its output no longer round-trips: several
files carry additions that a plain regeneration drops, including `PromiseAddr`,
the `DeploySimpleStorage` helper, and the `CrosschainMint` and `CrosschainBurn`
filters on `L2NativeSuperchainERC20`. Three files also share the `Identifier`
struct, which is declared once here rather than in each of them.

When a contract's ABI changes, update the affected file by hand, or regenerate
it with `abigen` and reapply those additions.
